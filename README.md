
# Projetos de Sites & Landing Pages

Repositório dedicado ao desenvolvimento de sites e landing pages, unindo design gráfico, experiências digitais, código e inteligência artificial.

## Sobre o projeto

Este repositório reúne projetos desenvolvidos para estudo, prática e criação de soluções digitais, explorando diferentes layouts, estilos visuais, interfaces e tecnologias web.

## O que você encontrará

- 🌐 Sites institucionais e portfólios
- 🚀 Landing pages de produtos e serviços
- 🎨 Interfaces com foco em design e experiência do usuário
- 💻 Projetos desenvolvidos com HTML, CSS e JavaScript
- 🤖 Experimentos com ferramentas de inteligência artificial

## Objetivo

Aprimorar minhas habilidades em desenvolvimento web, unir minha experiência em design gráfico à programação e construir projetos digitais funcionais, modernos e visualmente consistentes.
